# Décisions produit importantes

- L’application reste d’abord un Journal de Quêtes relié à la vie réelle.
- La collection est recentrée sur les créatures mythiques, les légendes et les cultures.
- Le hasard/gacha ne doit pas être le cœur de l’obtention des créatures.
- Le Housing est conservé, mais chaque nouveau biome possède un camp de base immédiatement lisible.
- Les objets principaux du camp ne peuvent pas être retirés.
- Les niveaux suffisent à débloquer les biomes et leurs éléments associés.
- Les objets Nature sont partagés entre les biomes ; les décorations culturelles restent propres à leur biome.
- Le système Manxiety est supprimé car trop culpabilisant et effrayant pour des enfants.
- L’interface doit privilégier la clarté, la bienveillance et les actions courtes.
- Les récompenses doivent donner envie sans casser une progression de plusieurs mois.
- Les tâches AFK doivent accompagner le travail réel, pas encourager une surveillance permanente de l’application.
