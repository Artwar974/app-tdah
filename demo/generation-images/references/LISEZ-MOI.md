# Les références à joindre

Toutes viennent du projet (jamais d’une autre application).

- `camp-jour.webp` : Le camp en une scène, le jour : l’angle de vue, l’échelle des objets, la lumière.
- `camp-nuit.webp` : Le camp la nuit : les lueurs, le temple, la guirlande.
- `tente4.webp` : La tente au niveau 4 (l’Auberge) : le style peint, l’ombre douce, l’échelle de référence des bâtiments.
- `objets-camp.webp` : La planche des objets du camp : le style à tenir pour tout nouvel objet.
- `feu.webp` : Le feu du camp (le seul grand feu).
- `hameau-doc.webp` : Le Hameau : le Kiosque et ses lanternes dans la doc.
- `sentier.webp` : L’écran du Grand Sentier (saison 1) : la bannière à remplacer, la bande des paliers.
- `sentier-saison2.webp` : Le même écran, saison 2 (Les vendanges).
- `promesse.webp` : L’écran de la promesse avec le sceau dessiné par le code.
- `defi.webp` : La feuille du défi du Hameau avec la guirlande dessinée en icônes.
- `ponton-parcours.webp` : Le Ponton quand le compagnon attend notre choix : les trois cartes « voie » (icônes provisoires).
- `matin.webp` : La feuille « Hier » (le résumé du matin) : l’endroit de la bannière.
- `icones-figures.webp` : Les icônes « Figures » et « Veillée » telles qu’elles s’affichent (page DA).
- `minotaure-morceaux.webp` : Les morceaux de la marionnette du minotaure (vue de face) : ce qu’il faut livrer pour un compagnon, dans cet ordre : torse, bras gauche, bras droit, jambe gauche, jambe droite, pagne, queue, têtes calme / content / dort.
- `minotaure-face.webp` : Le torse de face du minotaure : le style des personnages.
- `minotaure-json.txt` : Les champs du JSON de la marionnette (vues, morceaux, têtes, cadre, pied).
